# Tetris · 俄罗斯方块

Browser Tetris built with vanilla HTML, CSS, and JavaScript. No build step.

## Play locally

From this folder:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Then open [http://127.0.0.1:8080](http://127.0.0.1:8080).

Or open `index.html` directly in a browser.

## Controls

| Key | Action |
| --- | --- |
| ← / → | Move |
| ↑ | Rotate |
| ↓ | Soft drop |
| Space | Hard drop |
| P | Pause |

On narrow screens, on-screen touch buttons appear.
